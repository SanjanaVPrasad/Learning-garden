## Version boundary

The PDF and Word guide describe hosted release 24, including Calendar. The public source checked for this documentation was commit `0349190f60d348906fcdf08b9f8261c9f49040a8`, which does not include that calendar implementation. The files are included as hosted-product documentation, not as a claim that every described feature can run from this checkout. A source synchronisation is a separate roadmap item. This documentation update does not publish or change the private hosted site.

Research findings, adoption, time savings and model evaluations have not been established by writing these documents. Proposed work is labelled throughout.
