# Product brief: Learning Garden

Status: personal prototype. Audience and outcome statements below are hypotheses, not validated market findings.

## Problem and audience

The project began with a learner managing courses, roadmaps, study chats, notes and deadlines in different places. The initial audience hypothesis is a working professional learning technical skills alongside a full-time job who needs a manageable weekly plan and a retrievable learning record.

## Intended outcome

Help a learner choose a next action, follow through on a study session and retain a useful takeaway. Proposed measurements are first-session completion, time to retrieve a saved note and repeat weekly use. No measured improvement is claimed yet.

## Current scope

The repository contains a resource directory, priorities, roadmaps, monthly sprints, an action board, journal, Knowledge base, a study timer with charts, beginner Python practice and JSON backup import/export. The hosted product additionally has a calendar documented separately in the full guide; its source needs a separate repository update.

## Constraints and exclusions

Browser storage supports a simple personal prototype but does not provide automatic cross-device sync. The hosted site is private. The Python practice checks selected answers or expected output. There is no embedded paid AI tutor, automatic course-progress integration or arbitrary Python execution. This is not yet a validated multi-user learning platform.

## Product and AI contribution

Sanjana defined the user needs, learning priorities and requested interaction changes while using AI assistance for implementation. A portfolio case study should attach actual requirements, review notes and test evidence to specific releases. The product should be described as built with AI assistance; the current source does not establish an AI-powered teaching capability.
